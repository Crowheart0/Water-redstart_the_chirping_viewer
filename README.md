## 🪟 Windows 使用说明
从 [GitHub Releases](https://github.com/Crowheart0/Water-redstart_the_chirping_viewer/releases/latest) 下载 `Water-redstart_v3.6.0_windows_x64.exe`。无需安装 Python，双击即可运行；也可以把它放在桌面，通过 `文件 → 打开照片文件夹...` 选择图库。

## 🍎 macOS 使用说明

## ✨ 软件简介
Water-redstart 是专为摄影师、观鸟记录者以及需要从海量照片中**快速筛选出图**的用户打造的一款**本地极速看图工具**。

告别缓慢的文件夹拖拽和繁琐的复制粘贴操作，通过 Water-redstart: the chirping viewer，你只需使用键盘热键进行“快准狠”的二元判断（跳过或挑出），即可用极高效率梳理成百上千张单反照片。它被设计得轻量、活泼且极度流畅。

## 🚀 核心功能亮点

### 1. 极致交互：全键盘沉浸式筛选
- **[←] 左键**：回到上一张照片。
- **[→] 右键 / [D]键**：这张一般般，跳过下一张！
- **[↑] 上键 / [W]键**：这张很棒！一键选出并触发清脆的“叽叽”鸟鸣音效，自动将当前源文件安全复制到选中的独立子文件夹，毫不拖泥带水。
- **[↓] 下键 / [S]键**：看到一张想分享的高光时刻？直接将源文件路径放入系统剪切板（彻底解决大分辨率照片复制后体积膨胀变数百兆的问题），随时完美无损地粘贴到微信或文档中。
- **[A] 自动撤销**：手滑了？别着急，按下撤销键，自动退回上一张。如果是“挑出”手滑，程序会自动跟进帮你把刚才放进子文件夹里的废片删干净（放飞小鸟）。
- **[Space] 中心放大**：按住空格键开启相机般的“中心区域放大对焦”，松开自动完美复原到你之前的缩放和平移进度。（这颗按键现在也加入了自定义豪华大礼包！）
- **[I] 图片属性**：按下 I 键即可查看当前照片的详细身份信息（文件名、路径、尺寸、格式、大小、修改时间）。如果有 JPG+RAW 同名文件组，会自动弹出可爱的选择框让你挑选想查看哪一张~ （此按键同样支持自定义修改！）
- **顶端灵动进度条**：上方自带可视化进度条，使用鼠标拖动它就可以在全盘大跨度照片中进行快进和翻页！
- **灵活的倒序审图**：开启设置里的“倒序选片”，系统将一秒自动头尾翻转，方便您顺着刚刚拍摄完成的最新照片一直往前看！
- *以上所有热键（包含所有上下左右方向类与功能类热键）均可随时进入设置面板修改为您习惯的顺手按键！*

### 2. ⚡ RAW/巨型原图极速翻页体验
告别每翻一张 30MB 的原图就要卡顿转圈的噩梦！
- **全面支持更多 RAW 格式**：本版本新增支持 `.naw` 与 `.nrw` 格式文件，满足更多型号相机的看图需求。
- **重构的底层极速通道**：通过拦截并使用底层 C 库在图片读取阶段完成分辨率的降采样解码，使得巨型文件占用内存减半且画质锐利不降，体验飞升。
- **可取消的单线程预读**：后台只保留一个解码 worker 和最新位置的请求，快速翻页时会取消过期预读，避免线程堆积。普通模式最多向前预读 **12 张**，省内存模式 **4 张**；Super 模式启动时 **24 张**、之后 **16 张**。
- **高速连翻合并**：单次翻页立即显示；按住方向键连发时，最多每 120 ms 渲染一次，并跳过已经来不及显示的中间页，减少主线程同步解码和外接盘 I/O 抖动。

### 3. 🖱️ 沉浸式拖拽放大
- **鼠标滚轮局部缩放**：看鸟当然要数毛！使用鼠标滚轮可随心所欲悬停放大照片局部的细节。
- **左键平滑拖拽**：放大后支持鼠标左键按住拖动自由平移，享受顺滑细节审视体验！

### 4. 📂 智控文件夹与善后清理
- **智能记忆读图进度**：不想下次从大分类的第一张重看？不慌！软件会在停止翻页 500 ms 后合并保存最新进度，退出时也会立即保存。
- **贴心多功能结尾向导**：当你梳理完该目录下最后一张照片，程序会立刻为你颁发“小红花”，并直接弹出快捷处理面板：你可以选择一键无痕抹除已经挑废了的整个文件夹原片，甚至还可以让老版本看图程序上演“大义灭亲”——顺手把自己也删除得干干净净。
- **省内存模式 (v2.3新增)**：在设置菜单中开启时，向前预读数量从 12 张下降到 4 张，特别适合配置压力较大的老电脑或巨型 RAW 照片库。

## 🔧 [v3.6.0] 更新日志
1. **修复**：macOS 后台预读不再访问任何 Tk 变量，避免快速翻页时触发 Tcl/Tk 原生层崩溃。
2. **优化**：预读改为可取消的单 worker，缩小缓存窗口；高速翻页合并渲染，进度配置延迟合并写入。
3. **新增**：GitHub Actions 同时构建 Windows x64、Apple Silicon macOS 和 Intel macOS 安装包。
4. **修复**：更新检查按操作系统和 CPU 架构选择正确安装包；macOS 更新下载到“下载”文件夹，不修改正在运行的应用包。
5. **修复**：兼容 Tk 9 的 macOS 触控板精细滚动事件，并保留传统鼠标滚轮与 Linux 滚轮按钮缩放。

## 🔧 [v3.5] 更新日志

2. **修复**：EXIF 读取覆盖主 IFD 和子 IFD（`0x8769`），确保 Sony/Canon/Nikon 等相机参数完整提取。
3. **优化**：RAW 文件缩略图回退逻辑增强 —— 任一 EXIF 字段缺失（ISO/快门/光圈/焦距）均触发 rawpy 补全，所有厂商 RAW 格式均可正确显示相机参数。
4. **优化**：属性对话框高度从 550 增至 620，完整展示 ISO/快门/光圈/焦距。
